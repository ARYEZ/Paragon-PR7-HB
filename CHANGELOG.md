# Changelog

## 0.1.2

- The family list (`family.py`) knows the four newest Paragon apps: PR7-HX (hex editor), PR7-DB (SQLite browser),
  PR7-UN (uninstaller) and PR7-LN (launcher), so links between the apps and the PR7-U offer find them.

## 0.1.1

- The family's list knows the newest apps (PR7-HB, PR7-FS, PR7-AR, PR7-WM), so links between apps and Check for Updates find them.

## 0.1.0

- First release: a video converter that works the way HandBrake works, running the official HandBrakeCLI 1.11.2.
- Open a file, a disc folder or a folder of videos; titles, chapter / seconds / frames ranges.
- HandBrake's built-in presets, read from the engine itself (hardware ones only when this machine has the encoder),
  and your own: save, default, import, export, all in HandBrake's own file format.
- The seven tabs: Summary, Dimensions, Filters, Video, Audio, Subtitles, Chapters.
- The queue: progress, pause, stop, retry, activity logs, When done.
- Preview frames with the crop shown, and a 15-second live preview played in PR7-M.
- One finish for the whole family (OBSIDIAN / AURORA), Check for updates, and PR7-U knows it.
